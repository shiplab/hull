# Hull Generator

Makes a hull form quickly from a few inputs and by editing curves in three linked views (sheer plan, half-breadth plan, body plan), with a live 3D hull, hydrostatics, a Holtrop resistance estimate and a table of offsets to copy or save (for the [Ship Design Building Block Editor](https://shiplab.github.io/dbb/)).

Open `index.html` in a browser. It is one file and works offline.
